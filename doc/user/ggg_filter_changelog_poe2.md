# List of changes in actual filters made by GGG - Path of Exile 2

## Basically a list of all official forum threads and reddit posts containing filter-related information.

Most threads contain a lit of new map tiers, new mods, new item base types and new filter features.

*newest at the top*

### (2025.08.27) 0.3.0 (The Third Edict + Rise of the Abyssal) [Item Filter Information](https://www.pathofexile.com/forum/view-thread/3828542)

- [patch notes](https://www.pathofexile.com/forum/view-thread/3826682)
- Large amount of new item types and changes to existing items.
- *Items found in very high level areas that can have random quality can now have up to 30% quality*
- *Items that can have a maximum of 2 Sockets now have a very low chance of generating with 3 Sockets in high tier Maps.*
- *Items that can have a maximum of 1 Socket now have a very low chance of generating with 2 Sockets in high tier Maps.*
- *Added support for the `Import` keyword in item filters.*
- *Added support for multiple custom sounds in item filters.*

### (2025.06.06) 0.2.1

- [patch notes](https://www.pathofexile.com/forum/view-thread/3787044)
- *Added 21 new Endgame Runes* (Stated as 22 but there were only 21).
- *Added 15 new Endgame Soulcores.*
- *Added 7 new Endgame Talismans.*
- *Added 9 new Unique Items.*

### (2025.04.04) 0.2.0 (Dawn of the Hunt) [Item Filter Information](https://www.pathofexile.com/forum/view-thread/3740346)

- [patch notes](https://www.pathofexile.com/forum/view-thread/3740562)
- Many new currencies and other items.
- *Introduced the Twilight Reliquary Key.*
- *Item filter gem level filtering now applies to uncut gems.*
- *Fixed a bug in item filters where using ">=" to filter the number of sockets was not working.*

### (2024.12.06) 0.1.0 - Initial relase of the game

- Filters are (partially?) documented on [item-filter/about](https://www.pathofexile.com/item-filter/about) page (there are some PoE 2 exclusive rules). Rest is guesswork from PoE 1.
